Contributors filing an issue or opening a pull request find a Principles section in the form or
template, linking to the five [Principles
questions](https://github.com/dipbazz/trayi/blob/main/docs/contributing/index.md#principles) every
proposal answers. It's required when you propose a feature, and optional when you only report a
bug or a docs problem: whoever fixes it answers them in the pull request
([#368](https://github.com/dipbazz/trayi/issues/368)).
