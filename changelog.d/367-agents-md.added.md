Contributors working with an AI agent (Claude Code, Codex, GitHub Copilot or another) have an
`AGENTS.md` at the root that any agent reads first, and a [Working with an AI
agent](https://github.com/dipbazz/trayi/blob/main/docs/contributing/agents.md) page: what an agent
may do without asking, what it never does (such as removing a `needs:` label, which only a person
does after reading the review), what "done" means, how to work from a fork, and which files on
someone else's branch to read before starting an agent on it
([#367](https://github.com/dipbazz/trayi/issues/367)).
